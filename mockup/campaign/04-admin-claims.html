หมายเหตุ UX
  1. 1แท็บสถานะ (ทั้งหมด / รอตรวจ / อนุมัติแล้ว / ปฏิเสธ) พร้อมจำนวน และช่องค้นหา · รูปแบบเดียวกับหน้ารายการอื่นของระบบ (ตาราง + แท็บ + popup)
  2. 2ตารางแสดงเลขที่ · ลูกค้า · แคมเปญ/ขั้น + รางวัล + ข้อมูลสำคัญที่ลูกค้ากรอก · วันที่ขอ · สถานะ
  3. 3คอลัมน์ “จัดการ”: รอตรวจ → “ตรวจคำขอ” เปิด popup · อนุมัติแล้ว/ปฏิเสธ → “ดูรายละเอียด”
  4. 4popup ตรวจคำขอ สรุปลูกค้า/ขั้น/รางวัล · ยอดสะสม ณ วันที่ขอ เทียบเกณฑ์ขั้น · คำตอบในฟอร์มทุกช่อง · ประวัติ · ปุ่ม “อนุมัติ” (ส่งรางวัลตาม component ของขั้นนั้น) หรือ “ปฏิเสธ…” (ต้องกรอกเหตุผล แล้วสิทธิ์ของขั้นถูกคืน ลูกค้าส่งใหม่ได้)
กติกา / ข้อยกเว้น / สถานะ
  • สถานะ: รอตรวจ → อนุมัติแล้ว (ส่งรางวัลเข้าบัญชี/คิวรับของของลูกค้า) หรือ ปฏิเสธ (คืนสิทธิ์) · ดำเนินการแล้วแก้ไม่ได้
