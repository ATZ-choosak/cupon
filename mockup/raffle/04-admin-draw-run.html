  1. 14 ขั้นต่อเนื่อง: ขั้นที่เสร็จแล้วล็อกและเป็นสีเขียว ย้อนไปแก้ไม่ได้ ขั้นถัดไปกดได้เมื่อขั้นก่อนหน้าเสร็จเท่านั้น; ทุกขั้นบันทึกผู้ทำ + เวลา
  2. 2ขั้น ① (ปิดรับ + ประกาศกอง) ทำก่อนวันจับ: ระบบล็อกกอง คำนวณ commitment hash และเผยแพร่จำนวนสิทธิ์รวม + hash ที่หน้าลูกค้า ผู้ร่วมเห็นก่อนจับ จึงพิสูจน์ได้ว่าผลไม่ได้เลือกทีหลัง (สเปก 6.6 ข้อ 3)
  3. 3ปุ่มจับรางวัลจะกดได้เมื่อเช็คลิสต์ความพร้อมครบ (กองล็อก, งบจอง, พ้นเวลาประกาศขั้นต่ำ, กฎหมาย/ภาษี); เวลาจับอัตโนมัติตามกำหนดก็ได้ แต่ค่าเริ่มต้นให้แอดมินกดเอง
  4. 4กล่องยืนยัน: ต้องติ๊กรับทราบและพิมพ์คำว่า "จับรางวัล" ก่อนปุ่มยืนยันจะใช้งานได้; กดซ้ำไม่ได้ (ปุ่มปิดทันทีระหว่างประมวลผล และฝั่งเซิร์ฟเวอร์ใช้คีย์กันซ้ำ)
  5. 5ขั้น ③ แสดงผลทั้งหมดพร้อมเปิดเผย seed และผลเทียบ hash อัตโนมัติ; ตารางส่งออกเป็น CSV ได้; รายการนี้อ่านอย่างเดียว
  6. 6ขั้น ④ ประกาศแยกจากการจับ เพื่อให้แอดมินตรวจรายชื่อก่อนเผยแพร่ — แต่ "ผลจับ" ไม่สามารถเปลี่ยนได้ในช่วงนี้; ผู้ชนะสินค้า/ของใหญ่เข้าคิวคำขอรับของ + ฟอร์มข้อมูลจัดส่งเดียวกับแคมเปญ
  7. 7รางวัลชดเชยเป็นรายการใหม่ในตารางแยก (ไม่ทับผลเดิม) ต้องมีเหตุผล + ผู้อนุมัติ และปรากฏในหน้าบันทึกการลุ้นด้วยป้าย "ชดเชย"
กติกา / ข้อยกเว้น / สถานะ
  • ถ้าผู้ชนะไม่กรอกข้อมูลรับของภายในกำหนด สิทธิ์ในรางวัลสิ้นสุด — ไม่มีการจับใหม่โดยอัตโนมัติ แอดมินต้องตัดสินใจเป็นรายกรณีผ่านรางวัลชดเชย/บันทึกการอนุมัติ
  • ถ้ากองสิทธิ์เล็กกว่าจำนวนผู้ได้รับที่ประกาศ ระบบแจกเท่าที่มีและแจ้งแอดมินก่อนกดจับ (ไม่ปัดเศษ)
  • 1 สิทธิ์ถูกรางวัลได้ 1 ครั้ง; ลูกค้า 1 ราย ถูกรางวัลใหญ่ได้ไม่เกินเพดานต่อรอบ (ถ้าตั้งไว้) — ใบถัดไปในลำดับจะถูกจับแทน
  • จับไม่สำเร็จกลางทาง (ข้อผิดพลาดระบบ): ทั้งธุรกรรมย้อนกลับ ไม่มีผลบางส่วนปรากฏ และ hash/seed เดิมยังใช้ได้
ข้อที่ต้องตัดสินใจกับลูกค้า
  • จับด้วยมือแอดมินเท่านั้น หรือให้เซิร์ฟเวอร์จับอัตโนมัติตามเวลา (เสนอ: แอดมินกดเอง เพื่อให้มีผู้รับผิดชอบ)
  • อัลกอริทึมตรวจสอบสาธารณะ (รูปแบบ hash/seed/ตัวตรวจสอบ) ต้องตกลงกับทีมพัฒนาและเผยแพร่เป็นเอกสารสั้นๆ ให้ผู้ร่วมตรวจเองได้
  • ระยะเวลาให้ผู้ชนะกรอกข้อมูลรับของ (เสนอ 30 วัน) และกติกาเมื่อไม่ตอบกลับ
  • ถ้ามีหน้าที่หัก/ออกเอกสารภาษีของมูลค่ารางวัล ต้องเก็บข้อมูลเพิ่มจากผู้ชนะหรือไม่ — รอผลตรวจจากฝ่ายบัญชี
