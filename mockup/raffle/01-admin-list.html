ยังไม่มีกิจกรรม? (สถานะว่าง)
เมื่อยังไม่เคยสร้างกิจกรรม หน้านี้แสดงปุ่ม "สร้างกิจกรรมแรก" พร้อมลิงก์ไปคู่มือ 3 ขั้น: ตั้งทางเข้าสิทธิ์ → ตั้งรางวัล/น้ำหนัก → ตรวจเช็คลิสต์
สร้างกิจกรรมแรก
หมายเหตุ UX
  1. 1แจ้งเตือนอยู่บนสุดของหน้าเมื่อมีกิจกรรมสถานะ "ร่าง" ที่เช็คลิสต์ไม่ครบ ระบุว่าขาดข้อไหนและลิงก์ไปที่ขั้นตอน 5 ของตัวแก้ไขโดยตรง (หายไปเองเมื่อครบ)
  2. 2สถิติบนสุดนับเฉพาะเดือนปัจจุบัน; "จ่ายจริง" = มูลค่ารางวัลที่ส่งออกไปแล้วตามมูลค่า/ชิ้นที่ตั้งไว้ ไม่รวมงบที่จองสำหรับโหมด B ที่ยังไม่จับ
  3. 3ชิป A/B ต่อกิจกรรมแสดงว่ามีรางวัลโหมดใดบ้าง (กิจกรรมเดียวผสมได้ เพราะโหมดตั้งต่อรางวัล) พร้อมแท็กระยะพัฒนาของแต่ละโหมด
  4. 4แถบงบ: ตัวเลขหนา = จ่ายจริง, จางกว่า = งบที่ตั้ง; แถบเป็นสีเขียวตามปกติ สีส้มเมื่อ ≥ 90% ของงบ และสีแดง + chip "เกินงบ" เมื่อเกิน 100%; โหมด B แสดงยอดที่จองไว้ใต้แถบ
  5. 5ปุ่มหลักต่อแถวเปลี่ยนตามสถานะ: ร่าง = ตรวจเช็คลิสต์, เปิด = แก้ไข/รางวัลงบ, ปิดรับที่มีโหมด B = จับรางวัล, จับแล้ว = ดูผล; ทุกสถานะมีลิงก์ไป "บันทึก" ที่กรองกิจกรรมนั้น
  6. 6สถานะว่างของหน้ารายการ — ยังไม่มีกิจกรรมจึงมีเพียงปุ่มสร้าง ไม่แสดงตารางเปล่า
กติกา / ข้อยกเว้น / สถานะ
  • สถานะ: ร่าง (แก้ไขได้ทุกอย่าง) → เปิด (แก้ได้เฉพาะข้อความ/วันสิ้นสุด และเพิ่มจำนวนรางวัล) → ปิดรับ (หยุดออกสิทธิ์/ใช้สิทธิ์) → จับแล้ว (เฉพาะกิจกรรมที่มีโหมด B)
  • กิจกรรมที่เปิดแล้ว "ลบ" ไม่ได้ ปิดรับได้อย่างเดียว เพื่อคงบันทึกการลุ้นไว้ตรวจสอบ
  • ปุ่ม "จับรางวัล" ปรากฏเฉพาะกิจกรรมที่มีรางวัลโหมด B และถึงสถานะ "ปิดรับ" เท่านั้น
  • สิทธิ์ "ใช้แล้ว" ของโหมด B หมายถึงสิทธิ์ที่เข้ากองแล้ว (ยังไม่มีผล) จนกว่าจะจับ
ข้อที่ต้องตัดสินใจกับลูกค้า
  • ใครมีสิทธิ์สร้าง/เปิดกิจกรรม และใครอนุมัติงบ — เสนอ: สร้างได้โดยฝ่ายการตลาด, "เปิด" ต้องมีผู้อนุมัติงบจากฝ่ายบัญชี (ตรงกับข้อ "งบอนุมัติ" ในเช็คลิสต์)
