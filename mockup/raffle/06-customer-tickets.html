กรอกโค้ดที่พิมพ์แจกในกล่อง = 1 สิทธิ์ · วันนี้ใส่ได้อีก 3 โค้ด
หมายเหตุ UX
  1. 1สรุป 3 ตัวเลข: พร้อมใช้ (รวมทุกกิจกรรมที่เปิด), เข้ากองรอจับ (ใช้แล้วแต่ยังไม่ประกาศ), ใกล้หมดอายุ (≤ 14 วัน) — กดตัวเลขเพื่อกรองรายการ
  2. 2การ์ดต่อกิจกรรม: เลขใหญ่ = สิทธิ์พร้อมใช้, ชิป "จากพอยท์ 2 / จากยอดซื้อ 3 / จากโค้ดกล่อง 1" แยกตามทางที่ได้ (นับจากบันทึกจริง), แถบ "สะสมแล้ว x/เพดาน" บอกเพดานต่อรอบ; ปุ่มหลักเปลี่ยนตามโหมด (A = ลุ้นเลย, B = ลงกอง/ดูกอง)
  3. 3สถานะ "ครบเพดาน": การ์ดมีกรอบสีส้ม + ข้อความบอกสาเหตุ; ปุ่มรับสิทธิ์เพิ่ม (แลกพอยท์/กรอกโค้ด) ปิดสำหรับกิจกรรมนี้ แต่ใช้สิทธิ์ที่ถืออยู่ได้ตามปกติ
  4. 4สิทธิ์ที่เข้ากองโหมด B ถอนคืน/โอนไม่ได้ จึงแสดงเป็นสถานะแยกพร้อมลิงก์ไปหน้านับถอยหลังและกองสิทธิ์
  5. 5"รับสิทธิ์เพิ่ม" แสดงครบ 5 ทาง ทางที่กิจกรรมนี้ปิดอยู่จะจางและระบุเหตุผล; ปุ่มแลกพอยท์พาไปหน้าแลกของรางวัลของโมดูลพอยท์ (เลือกรายการ "สิทธิ์ลุ้น") เพื่อไม่ทำหน้าแลกซ้ำ
กติกา / ข้อยกเว้น / สถานะ
  • สถานะสิทธิ์: พร้อมใช้ · ใกล้หมดอายุ (≤ 14 วัน) · ใช้แล้ว · เข้ากองรอจับ · หมดอายุ — สิทธิ์ที่หมดอายุกู้คืนไม่ได้
  • ใช้สิทธิ์ที่ใกล้หมดอายุก่อนเสมอ (FIFO ตามวันหมดอายุ) เมื่อกดลุ้น
  • หน้าเปล่า (ยังไม่มีสิทธิ์): แสดงข้อความ "ยังไม่มีสิทธิ์ลุ้น" พร้อมปุ่มรับสิทธิ์ 5 ทางด้านล่างเหมือนเดิม
  • ถ้าบิลที่ให้สิทธิ์ถูกยกเลิก สิทธิ์ที่ยังไม่ใช้ถูกยกเลิก และแสดงข้อความในรายการ
ข้อที่ต้องตัดสินใจกับลูกค้า
  • ลูกค้า B2B หนึ่งบัญชีมีหลายผู้ใช้/สาขา — นับสิทธิ์ต่อบัญชีร้านค้า (เสนอ) หรือต่อผู้ใช้
  • ลูกค้าเลือกเองได้หรือไม่ว่าจะใช้สิทธิ์โหมด A หรือลงกอง B (เสนอ: เลือกเอง ใช้ได้เฉพาะสิทธิ์ที่ถือ ไม่ปนกัน)
