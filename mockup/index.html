◀ กลับหน้าหลัก cupon

MOCKUP สำหรับนำเสนอลูกค้า + ใช้เป็นแนวทาง dev

ระบบโปรโมชั่น · คูปอง · พอยท์ · แคมเปญ · สุ่มรางวัล · เซตร้านยาเปิดใหม่

ทุกหน้าเป็น HTML คลิกต่อกันได้ตาม flow จริง — สกินตามธีม pmpc (แดง #B32026, Noto Sans Thai, การ์ด/ปุ่ม/ตารางสไตล์ MUI เดียวกับหน้าแอดมินปัจจุบัน) แต่ละหน้าแนบ "หมายเหตุ UX" (วงเลขเหลือง) บอกพฤติกรรม กติกา และข้อที่ยังต้องตัดสินใจ · เริ่มจากกดการ์ดโมดูลด้านล่าง แล้วเปิดหน้า "ภาพรวม Flow" ของโมดูลนั้นก่อน

ทุกโมดูลไหลเข้าจุดเดียวกันตะกร้า/เช็คเอาต์ (โปรโมชั่น → คูปอง → พอยท์ที่ใช้ → ยอดสุทธิ)
ผลหลังชำระเงินได้พอยท์รายสินค้า · ยอดสะสมแคมเปญ · สิทธิ์ลุ้นรางวัล (Tickets)
รางวัลไม่ต้องสร้างระบบใหม่ไหลเข้ากระเป๋าคูปอง / ยอดพอยท์ / คิวคำขอรับของ ที่มีอยู่แล้ว
