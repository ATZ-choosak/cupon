ตั้งค่าแจ้งเตือนลูกค้า

ที่เดียวสำหรับทุกโมดูล — เปิด/ปิดเรื่องที่แจ้ง และตั้งจำนวนวันเตือน · ลูกค้าเห็นที่กระดิ่ง ศูนย์แจ้งเตือน และหน้าแรก

หมายเหตุ UX
  1. 1ตารางเรื่องที่แจ้งเตือน 6 เรื่อง: พอยท์ · แคมเปญสะสมยอด · คำขอรับรางวัล · คูปอง · โปรโมชั่น · สุ่มรางวัล — สวิตช์เปิด/ปิดต่อเรื่อง ช่องทางเดียวคือแจ้งเตือนในเว็บ
  2. 2ช่องตั้งค่าของแต่ละเรื่อง เช่น เตือนก่อนหมดอายุกี่วัน, ติ๊ก 80% / 95% ของแคมเปญ
  3. 3แสดงตัวอย่างข้อความที่ลูกค้าจะเห็น เพื่อให้ admin รู้ว่าตั้งแล้วได้ผลอย่างไร
  4. 4ส่วน “ลูกค้าจำลองเห็นอะไรตอนนี้” คำนวณสดจากค่าที่ตั้ง + ข้อมูลลูกค้าที่เลือกในแถบจำลอง — แก้ค่าแล้วเห็นผลทันที
กติกา / ข้อยกเว้น / สถานะ
  • ช่องทางแจ้งเตือนมีเฉพาะในเว็บ (กระดิ่ง + ศูนย์แจ้งเตือน + การ์ดหน้าแรก) ไม่มีการส่งข้อความออกนอกระบบ
  • แจ้งเตือนคำนวณจากสถานะปัจจุบันของลูกค้า: เมื่อเงื่อนไขหาย (เช่น ใช้พอยท์แล้ว) แจ้งเตือนหายเอง · อ่านแล้วจำเป็นรายรายการ
  • ปิดเรื่องใด ลูกค้าไม่เห็นแจ้งเตือนเรื่องนั้นทันที แต่ข้อมูลในโมดูลนั้นไม่เปลี่ยน
