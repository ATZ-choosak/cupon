ตั้ง “ใคร / สินค้าอะไร” ครั้งเดียวแล้วเลือกใช้ในทุกหน้าตั้งค่า — ถ้าตั้งเป็น “ทุกคน” ไม่ต้องสร้างกลุ่มเลย · “ได้อะไร” (ผลตอบแทน) ตั้งในแต่ละโมดูลเองด้วย component กลางที่ผสมได้หลายอย่าง

หมายเหตุ UX
  1. 1ไม่มีหน้า “ชุดของรางวัล” กลางแล้ว แนวคิดเดิม (รางวัลผสมกันเป็นชุดได้) ยังอยู่ แต่ย้ายเป็น component ผลตอบแทน ที่ฝังในหน้าของแต่ละโมดูล (โปรโมชั่น พอยท์ แคมเปญ สุ่มรางวัล) — เก็บแยกตามโมดูล ติดธง source_module ไม่ต้องไปสร้างชุดก่อนแล้วกลับมาเลือก
  2. 2ตัวเลือกกลุ่มเป้าหมายเป็น component เดียว ทุกหน้าตั้งค่าใช้ตัวเดียวกัน ไม่มีช่องเลือกรายชื่อแยกของใครของมัน
  3. 3ตรวจก่อนเผยแพร่ ข้อความ error บอกชัดว่าขาดอะไร และเก็บเป็นร่างได้ตลอด
  4. 4ตรวจที่เซิร์ฟเวอร์เสมอ ไม่พึ่งแค่การซ่อนปุ่มฝั่งลูกค้า
