การคำนวณราคา
  • ราคา Flash = ราคาปกติ × (1 − %) ปัดเป็นบาทเต็ม (ปัดขึ้นที่ .5)
  • ลด Flash ก่อน แล้วจึงตรวจโปรโมชั่นเงื่อนไข จากราคาที่ลดแล้ว
  • เกินโควตาระหว่างตะกร้าเดียว: ชิ้นที่เกินคิดราคาปกติ
หมายเหตุ UX
  1. 1ตั้งค่าแคมเปญ ชื่อ + วันเวลาเริ่ม–สิ้นสุด (ระดับนาที) · สิ้นสุดต้องหลังเริ่ม · ช่วงเวลาซ้อนกับแคมเปญอื่นที่มีกลุ่มสินค้าเดียวกัน ระบบเตือนและไม่ให้บันทึก
  2. 2เกิดซ้ำ "ครั้งเดียว" หรือ "ทุกปี (วันเดิม)" — ทุกปีคัดลอกการตั้งค่าไปปีถัดไปอัตโนมัติและรีเซ็ตโควตา (แอดมินแก้ได้ก่อนถึงวัน)
  3. 3กลุ่มสินค้า เลือกได้เฉพาะบางหมวด/กลุ่ม ตั้ง % ต่อกลุ่ม (เช่น 30% / 20% / 10%) · เพิ่ม/ลบแถวได้ระหว่างแคมเปญกำลังทำงาน (เพิ่มกลุ่มมีผลทันที)
  4. 4โควตาต่อรอบและความคืบหน้า นับเป็นชิ้นที่ขายได้ในราคาพิเศษ · แถบเขียว < 90% / เหลือง ≥ 90% / แดงเมื่อหมด · หมดโควตา = ราคากลับปกติเฉพาะกลุ่มนั้นทันที (ไม่รอหมดเวลา)
  5. 5คืนราคาอัตโนมัติ ล็อกเปิดไว้ ไม่ให้ปิด (เป็นหลักของโปรประเภทนี้) · ตั้งแจ้งเตือนแอดมินเมื่อโควตาใกล้หมดได้
  6. 6มุมมองลูกค้า + สถานะจำลอง ปุ่มสลับ "อยู่ในช่วงโปร / นอกช่วงโปร" ใช้เพื่อนำเสนอเท่านั้น ไม่เปลี่ยนข้อมูลจริง (ระบบจริงเช็คจากวันเวลาที่ตั้ง) · แบนเนอร์มีนาฬิกานับถอยหลัง การ์ดสินค้าขีดฆ่าราคาเดิม และป้าย "เหลือ N ชิ้น" เมื่อโควตาต่ำกว่า 20%
  7. 7กลุ่มลูกค้าเป้าหมาย ใช้ตัวเลือกเดียวกับทุกหน้า (ทุกคน / บางคน = เลือกจากกลุ่มลูกค้าที่ตั้งไว้ รวม-ยกเว้น) · เดิมเป็นช่อง “เพิ่มลูกค้า” รายคนในหน้านี้ — เปลี่ยนมาใช้กลุ่มเพื่อไม่ให้แก้รายชื่อซ้ำหลายที่ · ลูกค้านอกกลุ่มเห็นราคาปกติ
กติกา / ข้อยกเว้น / สถานะ
  • สถานะแคมเปญ: ตั้งเวลาไว้ → กำลังจัดอยู่ → จบแล้ว (หมดเวลา/หมดโควตาทุกกลุ่ม) · แก้ % ระหว่างจัดอยู่มีผลกับตะกร้าใหม่ ตะกร้าที่ค้างอยู่คิดใหม่ทุกครั้งที่โหลด
  • ใช้ได้กับลูกค้าที่กำหนดเท่านั้น (ทุกคน / บางคน) · ลูกค้านอกกลุ่มเห็นราคาปกติ ไม่เห็นแบนเนอร์
  • ถ้าสินค้าอยู่ทั้งในแคมเปญ Flash และโปรโมชั่นเงื่อนไข ลด Flash ก่อน แล้วโปรเงื่อนไขคิดจากราคาที่ลดแล้ว
ข้อที่ต้องตัดสินใจกับลูกค้า
  • โควตาต่อรอบนับ "ชิ้น" (ค่าเริ่มต้น) หรือ "ยอดเงิน" — spec ระบุได้ทั้งสองแบบ
  • ปัดเศษราคา Flash เป็นบาทเต็ม (ค่าเริ่มต้น) หรือเก็บสตางค์
  • ยอดที่ใช้นับเงื่อนไขโปรเงื่อนไขคิดจากราคาหลังลด Flash (ค่าเริ่มต้น) หรือราคาก่อนลด
  • มีโควตาต่อลูกค้า/ร้านด้วยหรือไม่ (ตอนนี้โควตาเป็นของทั้งรอบเท่านั้น)
