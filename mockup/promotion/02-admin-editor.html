  10. 10กลุ่มสินค้า ขอบเขตสินค้ามีตัวเลือก “กลุ่มสินค้าที่ตั้งไว้” จาก กลุ่มสินค้า ไม่ต้องกรอกซ้ำ
  11. 11โควต้าทั้งหมด ใหม่ จำกัดจำนวนสิทธิ์รวมของโปร (นับเป็นออเดอร์) แยกจากโควต้าต่อลูกค้า — ใช้คู่กันได้ เช่น 50 สิทธิ์ คนละไม่เกิน 2 · ตัดตอนชำระสำเร็จ · เต็มแล้วสถานะ “หมดโควต้า”
  12. 12จัดกลุ่มเงื่อนไข A ประเภท · B ขอบเขต · C สินค้าที่ต้องมี · D ตรวจหน่วยสินค้า · E เงื่อนไขลูกค้า — อยู่โซนเดียวกัน

  • ปุ่ม "บันทึก" แสดง toast สำเร็จ แล้วกลับหน้ารายการ · เกิดข้อผิดพลาดจากเซิร์ฟเวอร์ = dialog ไม่ปิด แสดง toast แดง
  • แก้โปรที่ใช้ไปแล้ว: ประวัติการใช้สิทธิ์เก็บ snapshot เงื่อนไข/ผลตอบแทนตอนใช้ ไม่เปลี่ยนตาม
  • โปรเดิม (Bundle) เปิดแล้วเห็นขอบเขต = เลือกรายสินค้า, ผลตอบแทน = ของแถม, ใช้ร่วม = ตามนโยบายร่วม
ข้อที่ต้องตัดสินใจกับลูกค้า
  • ลูกค้าเลือกโปรเองเมื่อเข้าเงื่อนไขหลายโปร — ต้องการให้ระบบ “แนะนำ” ชุดที่ประหยัดสุดล่วงหน้า (ติ๊กไว้ให้) หรือไม่ติ๊กอะไรเลย
  • ของแถมได้พอยท์หรือไม่ (ค่าเริ่มต้น = 0 พอยท์ เพราะราคา ฿0)
