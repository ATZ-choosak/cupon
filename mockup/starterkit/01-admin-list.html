"พอขาย N เซต" = ค่าต่ำสุดของ (สต็อกคงเหลือ ÷ จำนวนขั้นต่ำต่อเซต) ของสินค้าบังคับทุกตัว · ใกล้หมดเมื่อ ≤ 5 เซต · ถ้าตัวใดต่ำกว่าขั้นต่ำสำหรับ 1 เซต ระบบเปลี่ยนสถานะเป็น "สต็อกไม่พอ" และบล็อกการสั่งทันที

ปิดการขาย กับ สต็อกไม่พอ ต่างกันอย่างไร 6

"ปิดการขาย" แอดมินตั้งเอง — เซตหายจากหน้าลูกค้า · "สต็อกไม่พอ" ระบบตั้งให้ — ลูกค้ายังเห็นเซต แต่สั่งไม่ได้ และเปิดกลับเองเมื่อเติมสต็อกครบขั้นต่ำ

หมายเหตุ UX
  1. 1ข้อความคุมสิทธิ์: ไม่มีตัวเลือก "ผู้สั่งได้" ให้ตั้งในรายการ — B2B เท่านั้นเป็นค่าตายตัวของโมดูลนี้
  2. 2ตัวเลขสีแดงกดแล้วกรองแท็บ "สต็อกไม่พอ" — ไว้ให้แอดมินเห็นปัญหาก่อนลูกค้าชน
  3. 3ราคาต่ำสุด = เฉพาะสินค้าบังคับ − ส่วนลด · สูงสุด = บังคับ + ทางเลือกทั้งหมด − ส่วนลด · ใต้ตัวเลขคือราคาที่ลูกค้าเห็นเป็นค่าเริ่มต้น (ทางเลือกที่แอดมินตั้งเปิดไว้) · ส่วนลดแบบ % แสดงเป็น −5%
  4. 4คอลัมน์สุขภาพสต็อก: ชื่อสินค้าที่เป็นคอขวด + จำนวนเซตที่ขายได้ · แถวสีแดงอ่อน = ถูกบล็อก · มีบรรทัดแยกถ้าสินค้าทางเลือกหมด (ไม่บล็อกเซต)
  5. 5การดำเนินการ: แก้ไข → 02 · ทำซ้ำ = คัดลอกเซตเป็นร่างใหม่ (ปิดขาย) · ปิดการขาย → ยืนยันก่อน · สั่งแทนลูกค้า → 03 (ล็อกกับเซตนั้น) · เซตสต็อกไม่พอสั่งแทนไม่ได้เช่นกัน
  6. 6ปุ่ม "ปิดการขาย" ไม่กระทบออเดอร์เดิม และตะกร้าที่มีเซตนี้อยู่จะแสดง "เซตนี้ปิดการขายแล้ว" ตอนเปิดตะกร้า
กติกา / ข้อยกเว้น / สถานะ
  • สถานะที่เป็นไปได้: ขาย · ปิด · สต็อกไม่พอ (อัตโนมัติ — ถ้าแอดมินปิดขายอยู่ จะแสดง "ปิด" เป็นหลัก)
  • ยอดสั่งแล้ว นับจำนวนเซตในออเดอร์ที่ไม่ถูกยกเลิก รวมที่เซลล์สั่งแทน
  • ไม่มีรายการ: แสดง "ยังไม่มีเซต — สร้างเซตแรกของคุณ" พร้อมปุ่ม ＋ สร้างเซต
  • ทำซ้ำ: คัดลอกรายการสินค้า จำนวน ส่วนลด แต่ตั้งชื่อต่อท้าย "(สำเนา)" และสถานะ "ปิด" เสมอ
