หมายเหตุ UX
  1. 1flow ใหม่ของการสร้างชุด: ① เลือก template → ② ใส่ข้อมูลชุด → ③ ตัวอย่าง/ส่งออกไฟล์พิมพ์ · กด “＋ สร้างชุดคูปอง” จากรายการชุดแล้วมาที่หน้านี้ก่อน
  2. 2แกลเลอรี template 5 แบบ แสดงตัวอย่างหน้าบัตรจริง (ข้อมูลตัวอย่าง) · ตัวกรองชนิดสิทธิ์ ส่วนลด/ของฟรี จะทำให้แบบที่เหมาะขึ้นป้าย “แนะนำ” และแบบอื่นจางลง (ยังเลือกได้)
  3. 3เลือกสีบัตรได้ 4 สี (แดง Pharmaplex / น้ำเงิน / เขียว / ส้ม) — ทุก template เปลี่ยนสีตามทันที
  4. 4ตัวอย่างด้านขวาเป็นหน้า + หลังของ template ที่เลือก · ปุ่มด้านล่างสร้างชุดใหม่ที่ผูก template นี้แล้วไปหน้าใส่ข้อมูล · template “ตั๋วแลกของฟรี” ตั้งสิทธิ์เริ่มต้นเป็นของแถมให้
  5. 5ทางลัด “ทำซ้ำชุดเดิม” คัดลอก template สี ผู้รับ เงื่อนไข ไปเป็นชุดใหม่ (รหัสชุดใหม่ ต้องตั้งเอง)
  6. 6เปิดหน้านี้จากหน้าสร้าง/แก้ชุด (ปุ่ม “เปลี่ยน template”) จะเป็นโหมดเปลี่ยน — ตัวอย่างใช้ข้อมูลจริงของชุดนั้น ไม่มีส่วนทำซ้ำ และกดแล้วกลับไปหน้าแก้ไข
กติกา / ข้อยกเว้น / สถานะ
  • template กำหนดแค่หน้าตา (เลย์เอาต์/สี) — ข้อมูลชุด สิทธิ์ ผู้รับ ราคา ไม่เปลี่ยนตาม ยกเว้นตอนสร้างใหม่จาก “ตั๋วแลกของฟรี” ที่ตั้งสิทธิ์เริ่มต้นเป็นของแถม
  • ชุดที่เผยแพร่แล้วเปลี่ยน template/สีไม่ได้ (บัตรพิมพ์ไปแล้ว) ต้องทำซ้ำชุดเป็นชุดใหม่
  • ทุก template มีก้นคูปอง 22% และบาร์โค้ดรหัสชุดตำแหน่งเดิม — เครื่อง POS/ผู้นับก้นใช้ได้เหมือนกันทุกแบบ
ข้อที่ต้องตัดสินใจกับลูกค้า
  • ต้องการ template แบบไหนเพิ่ม (เช่น แนวตั้ง, ใส่โลโก้พาร์ทเนอร์ co-brand, ใส่รูปสินค้า) และให้แอดมินอัปโหลดโลโก้/รูปเองหรือให้ทีมออกแบบทำให้
  • ต้องการให้แอดมินสร้าง template ของตัวเองได้หรือไม่ (ตอนนี้เป็นชุดสำเร็จรูป 5 แบบ)
