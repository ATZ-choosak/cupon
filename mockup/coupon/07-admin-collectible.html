  1. 1สามแท็บ = สามวิธีให้สิทธิ์ ใช้ชุดฟิลด์ส่วนลดเดียวกัน ต่างกันที่ "วิธีรับ" · ใบหนึ่งอยู่ได้แท็บเดียว
  2. 2รูปแบบการแจกเลือกต่อใบ (กดรับเอง / แจกอัตโนมัติรายเดือน) — สร้างได้หลายใบพร้อมกัน เช่น ใบเก็บเอง + ใบรายเดือน
  3. 3จำนวนสิทธิ์ทั้งหมด = โควตารวม ตัดทันทีเมื่อลูกค้ากดเก็บ (แสดง "เหลือ n / ทั้งหมด" ให้ลูกค้าเห็น) · ว่าง = ไม่จำกัด
  4. 4การหมดอายุของสิทธิ์ที่เก็บแล้ว: วันที่คงที่ / N วันหลังเก็บ / สิ้นเดือนที่เก็บ — ช่องกรอกเปลี่ยนตามตัวเลือก
  5. 5ตัวอย่างฝั่งลูกค้าอัปเดตสดตามค่าที่ตั้ง ทั้งในศูนย์คูปอง (ก่อนเก็บ) และกระเป๋า (หลังเก็บ)
  6. 6แถบรายเดือน: ใช้แล้ว / พร้อมใช้ / รอวันที่ 1 — หมดอายุล็อกที่สิ้นเดือนเดียวกันเสมอ
  7. 7ลูกค้าใหม่: ออกอัตโนมัติเมื่อสมัคร/ยืนยันบัญชี ตรวจ "ยังไม่เคยสั่งซื้อ" และใช้ได้ครั้งเดียวต่อบัญชี (ล็อก)
  8. 8กลุ่มลูกค้าเป้าหมาย ทั้งแบบเก็บเอง และแบบแจกอัตโนมัติรายเดือน ใช้ตัวเลือกเดียวกับทุกหน้า · แจกรายเดือน: ระบบออกสิทธิ์ให้เฉพาะสมาชิกกลุ่ม ณ วันที่ออกสิทธิ์ (สมาชิกใหม่ที่เข้ากลุ่มกลางเดือนได้รอบถัดไป) · แบบเก็บเอง: คนนอกกลุ่มไม่เห็นคูปองในศูนย์คูปอง
กติกา / ข้อยกเว้น / สถานะ
  • ลูกค้าเก็บซ้ำเกิน "ต่อคน" ไม่ได้ — ปุ่มเปลี่ยนเป็น "เก็บแล้ว"; สิทธิ์ที่เก็บแล้วไม่หายถ้าแอดมินปิดการแจกภายหลัง
  • แก้เงื่อนไขส่วนลดของใบที่มีคนเก็บแล้ว: ใบที่เก็บไปแล้วใช้ค่าเดิมตอนเก็บ (snapshot) ยกเว้น "เงื่อนไขใช้ร่วม" ที่อ่านจากต้นทางสด
  • แจกรายเดือน: ไม่ทบข้ามเดือน ไม่ใช้ = หมดสิทธิ์ · ออกให้เฉพาะบัญชีที่ใช้งานอยู่
  • ลูกค้าใหม่ที่ยังไม่ยืนยันบัญชี จะยังไม่ได้รับคูปองจนกว่ายืนยัน
ข้อที่ต้องตัดสินใจกับลูกค้า
  • อายุคูปองลูกค้าใหม่ (ข้อเสนอ 30 วันนับจากวันที่ออก) และจะออกเมื่อ "สมัคร" หรือ "ยืนยันบัญชี"
  • ลูกค้าที่สมัครกลางเดือนจะได้สิทธิ์รายเดือนของเดือนนั้นทันทีหรือไม่ (ข้อเสนอ: ได้ทันที หมดสิ้นเดือน)
  • เพดานจำนวนสิทธิ์/วันที่ของคูปองเก็บเอง "ไม่จำกัด" อนุญาตหรือไม่ — ข้อเสนอให้บังคับกรอกโควตารวมเพื่อกันงบบาน
