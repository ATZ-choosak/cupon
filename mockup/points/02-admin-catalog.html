  1. 1ประเภท: คูปอง / ส่งฟรี / ของแถม / เครดิต / สิทธิ์ลุ้น — อ่านอัตโนมัติจากรายการในชุดของรางวัลที่เลือก (ชุดผสมแสดงหลายป้าย) ไม่ต้องเลือกซ้ำ · ประเภทกำหนดว่าออกอะไรให้ลูกค้าและไปอยู่ที่ไหนหลังแลก
  2. 2ได้รับ: สรุปสั้นของสิ่งที่ลูกค้าจะได้ (สร้างอัตโนมัติจากฟิลด์ในรายการ) เพื่อให้แอดมินเห็นผลโดยไม่ต้องเปิดแก้ไข
  3. 3คงเหลือ / โควตารวม: ลดลงทันทีที่มีคนแลก · เหลือ 0 → สถานะอัตโนมัติเป็น "หมดแล้ว" และลูกค้ากดไม่ได้ · เติมโควตาได้ภายหลัง · ของแถมใช้สต็อกที่จัดสรรเป็นโควตา
  4. 4ต่อคน: จำกัดจำนวนครั้งต่อลูกค้า 1 บัญชี รายเดือน/รายปี/ตลอดไป — ว่าง = ไม่จำกัด · ตรวจที่ฝั่งเซิร์ฟเวอร์ตอนกดแลก
  5. 5สถานะ: เปิดใช้งาน / ปิดชั่วคราว (ซ่อนจากลูกค้า) / หมดแล้ว / รอเปิด (ตามช่วงเวลา) · ปิดชั่วคราวไม่กระทบสิทธิ์ที่ลูกค้าแลกไปแล้ว
  6. 6ของรางวัลมาจากชุดของรางวัล: เลือกชุดแทนการกรอกประเภท/รายละเอียดเอง (ตัดตัวเลือก “ประเภทของรางวัล” 5 การ์ดเดิมออก) · รายการแลกล็อกเวอร์ชันของชุดไว้ — ชุดถูกแก้เป็นเวอร์ชันใหม่ รายการนี้ยังให้ของตามเวอร์ชันเดิมจนแอดมินกด “อัปเดต” · เปลี่ยนไปใช้ชุดอื่นในรายการที่มีคนแลกแล้วไม่ได้ ต้องสร้างรายการใหม่ (กันสิทธิ์เก่าคลาดเคลื่อน)
  7. 7ฟิลด์ตามประเภทอยู่ในชุดของรางวัล: คูปอง = ชนิด/มูลค่า/ขั้นต่ำ/อายุหลังแลก · ของแถม = สินค้า + จำนวน · เครดิต = บาท · สิทธิ์ลุ้น = กิจกรรม — หน้านี้แสดงสรุปอ่านอย่างเดียว · ของแถมจริง: สต็อกที่จัดสรรให้การแลกคือ “โควตารวม” ของรายการนี้
  8. 8ของจริงเข้าคิวเดียวกับแคมเปญ: ลูกค้ากรอกที่อยู่แล้วทีมหลังบ้านจัดการต่อในคิวคำขอรับรางวัล — ไม่ต้องมีคิวแยกสำหรับพอยท์
  9. 9พอยท์ที่ใช้: เป็นจำนวนเต็ม > 0 · แก้ได้ตลอด มีผลกับการแลกครั้งถัดไป · ระบบเตือนถ้าตั้งต่ำกว่ามูลค่าของรางวัลจริงมากผิดปกติ
  10. 10ใครแลกได้ ตัวเลือกกลุ่มเป้าหมายเดียวกับทุกหน้า (ทุกคน / บางคน = กลุ่มลูกค้าที่ตั้งไว้) ต่อรายการแลก — เช่น ของพรีเมียมเฉพาะร้าน VIP · ลูกค้านอกกลุ่มไม่เห็นรายการในหน้าแลก
