กติกาหลัก
  • พอยท์คิดรายสินค้า ไม่ใช่จากยอดบิล — พอยท์ = Σ(จำนวน × พอยท์ต่อหน่วยของสินค้านั้น × ตัวคูณแคมเปญ) สินค้าควบคุมราคา ยาน้ำ นมผง หรือราคาพิเศษตั้งเป็น 0 ได้
  • เข้าบัญชีทันทีที่ชำระเงินสำเร็จ ไม่ต้องกดแปลงหรือรออนุมัติ
  • ตัวคูณซ้อนกันคือบวกกัน เช่น ×1.5 + ×2 → ×3.5 (ไม่ใช่ 1.5 × 2 = 3)
  • วันหมดอายุตั้งต่อรอบ/ต่อแคมเปญ ไม่ใช่นโยบายเดียวทั้งระบบ — มีค่าเริ่มต้น แล้ว override รายแคมเปญได้
  • แลกแล้วหักทันที ใช้สิทธิ์ได้ทันที และยกเลิกการแลกเองไม่ได้ (ต้องให้แอดมินปรับ)
  • ยอดสะสมแคมเปญเป็นบัญชีแยก ไม่ถูกหักเมื่อแลกพอยท์ และแปลงเป็นพอยท์ไม่ได้ (ใช้ปลดล็อกขั้นบันไดรายปีเท่านั้น)
  • ยกเลิกออเดอร์ → หักพอยท์ที่ออเดอร์นั้นให้คืนอัตโนมัติ (เปิด/ปิดได้ที่นโยบาย) แต่ไม่เรียกคืนรางวัลที่แลกไปแล้ว
  • ไม่มีการแจ้งเตือนทาง SMS / อีเมล / LINE — เตือนพอยท์หมดอายุเป็นแถบบนเว็บเท่านั้น (นโยบายร่วมของระบบ)

ของพรีเมียมรอตรวจสอบ กำลังเตรียม ส่งแล้วเข้าคิวคำขอรับของเดียวกับรางวัลแคมเปญ

แคมเปญตัวคูณพอยท์ตั้งที่แคมเปญ แล้วมาซ้อน (บวก) ตอนคิดพอยท์ · ยอดสะสมแคมเปญเป็นบัญชีแยก · ของพรีเมียมที่แลกเข้าคิวคำขอรับของเดียวกับรางวัลแคมเปญแคมเปญ: รายการ · คิวคำขอรับรางวัล · ขั้นบันไดของฉัน
คูปองแลกคูปองลด/ส่งฟรี ได้คูปองออนไลน์เข้ากระเป๋าทันที ใช้ตามกติกาคูปอง (ยอดขั้นต่ำ วันหมดอายุ)ศูนย์คูปอง + กระเป๋า
สุ่มรางวัลแลกพอยท์เป็นสิทธิ์ลุ้น (Ticket) หนึ่งในทางเข้าสิทธิ์ของกิจกรรม — ระยะถัดไปสิทธิ์ลุ้นของฉัน · รายการกิจกรรม
โปรโมชั่นพอยท์คิดจากสินค้าที่ซื้อจริง ไม่รวมของแถมที่ได้ฟรี (ของแถม = 0 พอยท์) · ราคาหลังหักส่วนลดไม่มีผลต่อพอยท์ เพราะคิดต่อหน่วยตะกร้า: โปรที่ได้รับ

หมายเหตุ UX
  1. 1ตั้งก่อนขาย: อัตราพอยท์รายสินค้า (รวมตั้งตามแบรนด์/หมวด) + ตัวคูณแคมเปญ + นโยบายหมดอายุ — สินค้าที่ยังไม่ตั้งใช้ "ค่าเริ่มต้นเมื่อสินค้าไม่ได้ตั้งไว้"
  2. 2ตั้งรายการแลก: ประเภท พอยท์ที่ใช้ โควตารวม/ต่อคน สถานะ — ปิดชั่วคราวได้โดยไม่กระทบสิทธิ์ที่ลูกค้าแลกไปแล้ว
  3. 3ลูกค้าเห็นพอยท์ก่อนจ่าย: การ์ดสินค้า → ตะกร้า (รายการละเอียด) → หน้าผลลัพธ์หลังชำระ เพื่อให้เห็นว่าซื้ออะไรได้พอยท์เท่าไร
  4. 4คิดที่เซิร์ฟเวอร์: ตัวเลขบนหน้าจอเป็นประมาณการ ยอดจริงคำนวณที่ระบบตอนชำระสำเร็จ (ใช้อัตราและตัวคูณ ณ เวลาที่ชำระ)
  5. 5เข้าทันที: ไม่มีขั้นตอนกดรับ/แปลง — แต่ละออเดอร์สร้างล็อตใหม่ 1 ล็อต (ฐาน + ส่วนเพิ่มจากตัวคูณ) พร้อมวันหมดอายุ
  6. 6แลกแล้วย้อนไม่ได้เอง: ต้องผ่านหน้าต่างยืนยันที่แสดงยอดคงเหลือหลังแลก — ถ้าแลกผิด ต้องติดต่อแอดมินเพื่อปรับพอยท์
  7. 7ออกสิทธิ์ทันที: คูปอง→กระเป๋าคูปอง · ของพรีเมียม→คิวคำขอรับของ (ลูกค้ากรอกที่อยู่/ฟอร์ม) · เครดิต→ยอดเครดิตในบัญชี · สิทธิ์ลุ้น→Tickets
  8. Aยกเลิกออเดอร์: หักคืนเท่ากับที่ออเดอร์นั้นให้ไว้ (ทั้งฐานและส่วนเพิ่ม) ตามนโยบายที่เปิดไว้ ถ้าพอยท์ถูกแลกไปแล้วจะหักได้เท่าที่เหลือในบัญชี (ดูข้อที่ต้องตัดสินใจ)
  9. Bหมดอายุ: ระบบตรวจทุกคืน ขึ้นแถบเตือนที่ 30 และ 7 วันก่อน แล้วตัดล็อตที่หมดอายุ — ไม่มีการส่ง SMS/อีเมล/LINE
  10. Cปรับด้วยมือ: ทำได้เฉพาะแอดมินที่มีสิทธิ์ ต้องใส่เหตุผล เกินวงเงินต้องให้ผู้จัดการอนุมัติ ทุกรายการมี audit "ใครทำ เมื่อไหร่"
กติกา / ข้อยกเว้น / สถานะ
  • ลำดับหักตอนแลก: หักล็อตที่ใกล้หมดอายุก่อน (เพื่อไม่ให้ลูกค้าเสียพอยท์โดยไม่จำเป็น)
  • ของแถมจากโปรโมชั่นและสินค้าราคา 0 ไม่ให้พอยท์; สินค้า 0 พอยท์ยังนับเข้ายอดสะสมแคมเปญได้ตามกติกาแคมเปญ (แยกบัญชี)
  • คืนสินค้า/ยกเลิกหลังจากลูกค้าใช้สิทธิ์ที่แลกไปแล้ว: ไม่เรียกคืนสิทธิ์ที่ใช้แล้ว (นโยบายร่วม §1.6) — หักได้เท่าที่เหลือในบัญชี

  • ใช้อัตราตามยอดบิล (ทุก ฿100 ได้ X พอยท์) แทนอัตรารายสินค้าได้ไหม — ต้นแบบสถิตเดิมใช้แบบตามยอดบิล แต่ spec ที่อนุมัติคิดรายสินค้า
