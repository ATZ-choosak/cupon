# จำลองระบบโปรโมชั่น — Pharmaplex

Prototype ทดลองแนวคิด 2 ระบบ ไม่ต้อง build ไม่ต้องมี server มีลิงก์สลับกันได้ในหน้า (มุมบนซ้าย)

## วิธีเปิด

ดับเบิลคลิก `showcase.html` (หน้าหลัก — ภาพรวมระบบ, สำหรับนำเสนอลูกค้า) เปิดด้วยเบราว์เซอร์ได้เลย มีเมนูสลับไปหน้าจำลอง A/B ที่กดเล่นได้จริง

## ไฟล์ในนี้

- `showcase.html` + `showcase.css` — **หน้าหลัก** ภาพรวมระบบทั้งหมดสำหรับนำเสนอลูกค้า เน้นภาพ กดโต้ตอบได้บางส่วน: โปรโมชั่น (ซื้อคู่สินค้าที่เข้ากัน, ลดตามวัน, ส่วนลดท้ายบิล/ส่งฟรี), คูปอง (กระดาษพิมพ์แจกหน้าบูท, เก็บล่วงหน้า, สิทธิ์รายเดือน), สะสมพอยท์, แคมเปญ (custom field ฟอร์มรับสิทธิ์, ไม่มีกำหนดวันหมดสิทธิ์, แบบคนแรกที่ถึงเกณฑ์)
- `index.html` + `app.js` — **ระบบ B** แคมเปญสะสมข้ามบิล: milestone ขั้นบันไดหนึ่งแคมเปญ แต่ละขั้นเลือกเงื่อนไขปลดล็อกได้อิสระ — 🪜 **ขั้นบันได** (ปลดล็อกตามยอดสะสมของลูกค้ารายนั้นเอง, slider จำลองยอด) หรือ 🏁 **คนแรกที่ถึงเกณฑ์** (ต้องถึงยอด + ยังเหลือโควตา แข่งกับลูกค้าคนอื่น มีปุ่มจำลองคนอื่นมาแย่งโควตา) ผสมสองแบบในแคมเปญเดียวกันได้ ตั้งค่าฝั่งแอดมินต่อขั้น (เงื่อนไข ยอดเกณฑ์ ชื่อ ประเภทรางวัล ฟิลด์ข้อมูลที่ต้องขอ) คำขอรับรางวัลทุกขั้นไหลเข้าคิวรวมเดียวกัน
- `system-a.html` + `app-a.js` — **ระบบ A** ส่วนลดต่อบิล: จัดการสินค้า, ตะกร้าสินค้าจริง, ส่วนลดอัตโนมัติตามแบรนด์, คูปอง, แยกคิดค่าส่งตามกลุ่มสินค้า
- `style.css` — ดีไซน์/ธีมร่วมของทุกหน้า (รองรับ light/dark ตามเครื่อง)
- `explain.html` — เอกสารกระบวนการ/มติภายใน (ไม่ผูกกับเมนูหลักแล้ว เปิดตรงได้ถ้าต้องใช้อ้างอิงเอง)

ตรรกะทั้งหมดเป็น vanilla JS ล้วน ไม่พึ่ง library ภายนอก

## เล่นยังไง — ระบบ B (index.html)

1. ลากแถบเลื่อนบนสุด หรือกดปุ่ม preset เพื่อจำลอง "ยอดสะสม" ของลูกค้า 1 ราย
2. ดูรางวัลแต่ละขั้นเปลี่ยนสถานะ ล็อก → ปลดล็อก → กดขอรับสิทธิ์
3. แก้ค่าฝั่ง "ตั้งค่าฝั่งแอดมิน" ด้านล่าง (ยอดเกณฑ์ ชื่อ ประเภทรางวัล จำนวนสิทธิ์ ข้อมูลที่ต้องขอเพิ่ม) แล้วดูผลที่มุมมองลูกค้าด้านบนเปลี่ยนตามทันที
4. กด "ขอรับสิทธิ์" บนการ์ดที่ปลดล็อกแล้ว กรอกฟอร์ม แล้วดูรายการไปโผล่ใน "คิวคำขอรับรางวัล" ฝั่งขวา — จำลองงานที่ทีมปฏิบัติการต้องทำต่อ (โดยเฉพาะของนอกระบบที่ auto-fulfill ไม่ได้)
5. ปุ่ม "รีเซ็ตค่าเริ่มต้น" มุมบนขวาล้างกลับไปที่ข้อมูลตัวอย่างเดิม

## เล่นยังไง — ระบบ A (system-a.html)

1. กด +/− หยิบสินค้าใส่ตะกร้าทางซ้าย (มีทั้งกลุ่มฟรีค่าส่งได้ 🟢 และกลุ่มยกเว้น 🔴)
2. ดูยอดคำนวณสดด้านล่าง — ส่วนลดอัตโนมัติ (ตามแบรนด์ Blackmores) ตัดก่อนเสมอ
3. กรอกโค้ด `WELCOME300` หรือกดเก็บคูปอง `FREESHIP` แล้วกดใช้จากกระเป๋า ดูค่าส่งแยกคิดตามกลุ่มสินค้าจริง
4. แก้กติกาฝั่งแอดมินด้านล่าง (ยอดขั้นต่ำ ส่วนลด เปิด/ปิดให้เก็บล่วงหน้า เพิ่ม/ลบคูปอง) แล้วดูผลเปลี่ยนทันทีด้านบน
5. ปุ่ม "รีเซ็ตค่าเริ่มต้น" ล้างตะกร้าและกติกากลับไปที่ตัวอย่างเดิม

ข้อมูลทั้งหมดอยู่ใน memory ของหน้าเว็บเท่านั้น ปิด/รีเฟรชแล้วหาย — เป็น prototype สำหรับคุยไอเดีย ไม่ใช่ระบบจริง
